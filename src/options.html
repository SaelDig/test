ℹ️ Comment obtenir un token API ?

  1. Allez sur Atlassian Account Settings
  2. Cliquez sur "Create API token"
  3. Donnez un nom à votre token (ex: "JIRA Time Logger")
  4. Copiez le token généré et collez-le ci-dessus

⚠️ Le token ne sera affiché qu'une seule fois. Conservez-le en lieu sûr.
